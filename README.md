# StudyTrack

## Study Planner and Assignment Tracker

StudyTrack is a Python web application designed to help college students organize assignments, due dates, priorities, and completion status in one place. Students will be able to add and manage assignments, filter their workload, track completed work, and use a generative AI feature to receive study-plan suggestions.

## Technology

The application will be developed in Python using Streamlit.
